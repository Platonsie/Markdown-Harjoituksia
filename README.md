# Markdown-Harjoituksia

Minun ensimainen projekti on markdown landuage.

Markdown-kielessä on erilaisia merkkejä, jotka muuttavat tekstin muotoilua. Esimerkiksi merkki # muuttaa otsikon kokoa. Mitä enemmän risuaitoja (#) käytetään, sitä pienempi otsikkotaso on.

Voin näytä enemmän merkia. 

(*) (_) ne tekevät kursivointi (*terve*) (_terve_)

(**) jos käytä tupla tähti, se on lihavointi (**terve**)
